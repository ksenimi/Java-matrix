# Матрицы комплексных чисел

Практическая работа: консольная программа на Java 8 для операций с матрицами комплексных чисел.

## Возможности

- Создание и просмотр матриц `A` и `B` произвольного положительного размера.
- Сложение `A + B` при одинаковых размерах.
- Умножение `A × B`, если число столбцов `A` равно числу строк `B`.
- Деление `A / B = A × B⁻¹`, если `B` квадратная и невырожденная, а число столбцов `A` равно размеру `B`.
- Транспонирование `A` или `B` без комплексного сопряжения.
- Вычисление определителя квадратной матрицы `A` или `B`.

Определитель вычисляется методом Гаусса с выбором ведущего элемента. Обратная матрица для деления находится методом Гаусса — Жордана. Исходные матрицы при выполнении операций не изменяются. При несовместимых размерах и делении на вырожденную матрицу программа сообщает об ошибке.

## Запуск

Нужен JDK 8 или новее. В каталоге с исходниками выполните:

```text
javac -encoding UTF-8 Complex.java ComplexMatrix.java Main.java
java Main
```

В старой командной строке Windows для правильного вывода русского текста сначала выполните `chcp 65001`.

Выберите в меню создание матриц `A` и `B`. Для каждого элемента введите **действительную и мнимую части** через пробел. Например, строка `2.5 -3` задаёт число `2.5 - 3i`. Дробную часть вводите через точку. После создания матриц выберите нужную операцию по номеру в меню.

## Файлы

- `Complex.java` — неизменяемое комплексное число и арифметические операции.
- `ComplexMatrix.java` — матрица и операции над ней.
- `Main.java` — консольное меню и ввод матриц.
